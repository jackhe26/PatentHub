# PatentHub Web 局域网部署指南

## 📋 概述

本文档说明如何将 PatentHub Web 版部署到局域网，让同事通过浏览器访问使用。

## 🏠 部署架构

```
┌─────────────────────────────────────────────────────────┐
│  同事电脑（任意浏览器）                                   │
│  访问 http://192.168.x.x:1212/                          │
└─────────────────┬───────────────────────────────────────┘
                  │ 局域网
┌─────────────────▼───────────────────────────────────────┐
│  部署机（你的电脑）                                       │
│  ┌─────────────────────────────────────────────┐        │
│  │  静态文件服务器 (npx serve)                  │        │
│  │  端口：1212                                  │        │
│  │  监听：0.0.0.0（所有网卡）                   │        │
│  └─────────────────────────────────────────────┘        │
└─────────────────────────────────────────────────────────┘
```

## 🚀 快速部署（Windows）

### 第一步：配置防火墙（只需执行一次）

1. 右键点击 `setup-firewall.bat`
2. 选择「以管理员身份运行」
3. 等待配置完成

### 第二步：启动服务器

1. 双击 `start-web.bat`
2. 首次运行会自动构建生产版本
3. 等待服务器启动

### 第三步：获取本机 IP

打开命令提示符（CMD），输入：
```cmd
ipconfig
```

找到「IPv4 地址」，例如 `192.168.1.100`

### 第四步：同事访问

同事在浏览器中打开：`http://192.168.1.100:1212/`

---

## 🚀 快速部署（Mac）

### 第一步：赋予脚本执行权限

```bash
chmod +x start-web.sh
chmod +x setup-autostart.sh
```

### 第二步：启动服务器

```bash
./start-web.sh
```

### 第三步：获取本机 IP

打开终端，输入：
```bash
ifconfig | grep "inet "
```

找到类似 `192.168.1.100` 的地址

### 第四步：同事访问

同事在浏览器中打开：`http://192.168.1.100:1212/`

---

## ⚙️ 配置开机自启动（可选）

### Windows

1. 右键点击 `setup-autostart.bat`
2. 选择「以管理员身份运行」
3. 选择 1 启用开机自启动

### Mac

```bash
./setup-autostart.sh
# 选择 1 启用开机自启动
```

## ❓ 常见问题

### Q: 同事无法访问？

1. 确认服务器已启动（CMD 窗口不要关闭）
2. 确认 IP 地址正确
3. 确认防火墙已配置（运行 setup-firewall.bat）
4. 确认在同一局域网内

### Q: 端口被占用？

修改 `package.json` 中的端口：
```json
"serve:web": "npx serve ./release/app/dist/renderer -l tcp://0.0.0.0:新端口"
```

然后同步修改启动脚本中的端口。

### Q: 如何停止服务器？

在运行 `start-web.bat` 的 CMD 窗口按 `Ctrl+C`

### Q: 如何更新版本？

1. 拉取最新代码：`git pull`
2. 重新启动服务器：`start-web.bat`
   - 脚本会自动检测并重新构建

## 🔧 手动命令

如果不想用脚本，也可以手动执行：

### 构建生产版本
```bash
pnpm run build:web
```

### 启动服务器
```bash
pnpm run serve:web
```

### 查看本机 IP
```bash
# Windows
ipconfig | findstr "IPv4"

# Mac/Linux
ifconfig | grep "inet " | awk '{print $2}'
```
