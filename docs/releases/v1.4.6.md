# PatentHub v1.4.6

发布日期：2026-10-25

## ✨ 新增

- 新增审查搭档「科普大白」（第 2 位）：把权利要求逐条改写成「原文 / 比喻 / 总结」三列表格，并输出 R1–R12 核对报告与一句话总览；支持 `/2`、`/kpdb`、`/科普` 快捷调用。

## 🔧 改进

- 内置审查搭档重新编号：科普大白为 02，原 02–09 顺延为 03–10，展示序号、`/序号` 与 ID 编号保持一致。
- 新增会话搭档 ID 自动迁移（含 V1 时期遗留 id），修复旧会话顶部搭档显示、搭档 Chip 缺失及手动移除后提示词残留。
- 架构文档脚本与图示同步为 10 个审查搭档。
- 新增单元测试：搭档 ID 迁移、斜杠命令序号 / 拼音 / 中文检索。

## 🐛 修复

- **屏蔽上游 Chatbox 自动更新源**：默认完全关闭自动更新，不再访问 chatboxai.app；未配置自家更新源时隐藏「自动更新 / Beta 更新」开关；`install-update` 增加双重安全校验。
  如需启用自家更新源，见 `docs/auto-update.md`（构建时设置 `PATENTHUB_UPDATE_URL`）。
